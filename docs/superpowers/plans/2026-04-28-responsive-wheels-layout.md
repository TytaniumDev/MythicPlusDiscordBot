# Responsive Wheels Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the wheels view fill its viewport better in thin/tall windows by docking the Groups panel to the bottom in portrait orientations and letting tank/healer wheels grow larger than DPS in width-limited windows.

**Architecture:** CSS-only layout switch driven by viewport aspect ratio. The single 6-column wheels grid is split into two row-level grids (top: 2 cols, bottom: 3 cols) so each row sizes its wheels to fill its width independently. A new `useIsBottomStrip` hook + a `strip` variant of `GroupCard` handle the bottom-docked panel layout.

**Tech Stack:** React + Vite (`activity/`), CSS (no preprocessor), Storybook 9, Playwright (in Docker), Vitest.

**Spec:** `docs/superpowers/specs/2026-04-28-responsive-wheels-layout-design.md`

**Files:**

- Test: `activity/src/hooks/useMediaQuery.test.ts` (new)

- [ ] **Step 3: Add the hook**

In `activity/src/hooks/useMediaQuery.ts`, append:

```ts
/**
 * True when the viewport is wide enough to escape carousel mode but
 * portrait-ish (aspect ratio < 1.2:1). At these dimensions the Groups
 * panel docks to the bottom of the wheels view as a horizontal strip.
 *
 * Threshold is 6/5 (= 1.2). Tweakable in CSS-aligned media query below.
 */
export function useIsBottomStrip(): boolean {
  return useMediaQuery('(min-width: 600px) and (max-aspect-ratio: 6/5)');
}
```
